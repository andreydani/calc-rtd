Real-time data from Excel RTD servers, in LibreOffice Calc

Your data vendor feeds live values to Excel through an RTD formula. calc-rtd makes the same formula work in Calc. Free and open source.

Install in three steps

You need Windows, LibreOffice and the RTD server your data vendor installs. Nothing else.

  1. Download

    Get calc-rtd-win64.oxt with the button above.

  2. Add to LibreOffice

    Open Tools > Extensions, click Add and pick the file.

  3. Restart and type

    Restart LibreOffice and type your =RTD(...) formula as in Excel.

Try it right away

This formula needs no vendor and no setup. If the cell shows the time ticking, everything is working:

=RTD("calcrtd.sim";;"clock")

 

Then use your vendor's formula, exactly as it is written in Excel:

=RTD("Vendor.ProgID";;"TOPIC1";"TOPIC2")

How it works

The extension adds the function; a small helper program does the talking.

LibreOffice Calc

The extension adds the RTD function and updates the cells as values arrive.

↔

calc-rtd bridge

A helper program, started in the background, that plays the part Excel normally plays.

↔

Vendor's RTD server

The same component your data vendor installed for Excel. Nothing changes on their side.

The helper only accepts connections from your own user account on your own computer, and closes about a minute after LibreOffice does.

What the cells can show

Cell showsMeaning
#N/AWaiting for the first value, as in Excel. The very first start takes a few seconds.
#RTD: bridge offlineThe helper program could not be started. Check that your antivirus did not block calc-rtd-bridge.exe.
#RTD: ...A message from the RTD server or about it, for example an unknown ProgID.
#NAME?The extension is not installed, or the formula was copied from Excel (see the note on the right).

Good to know

  • Copying from Excel. Copied cells arrive as =_xlfn.RTD(...) and show #NAME?. Fix them all at once with Edit > Find & Replace: search for _xlfn., replace with nothing, and choose "Search in: Formulas". Save your work as .ods.
  • Do not use "Run as administrator". Start LibreOffice the normal way, like the program that feeds your RTD server.
  • Security warnings. The helper program is not code-signed, so Windows SmartScreen or your antivirus may warn about it. It is built from the public source code. A variant without any executable is available on the releases page.
  • 32-bit RTD servers. If your formulas report that the server is not registered, install calc-rtd-win32.oxt instead.
  • Windows only. RTD servers are a Windows technology. Your data vendor's terms of use still apply.
