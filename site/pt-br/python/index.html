Servidores RTD do Excel, em Python

Receba dados em tempo real de servidores RTD (RealTimeData) em qualquer programa Python, sem o Excel. O mesmo motor do calc-rtd para LibreOffice Calc, usável por conta própria.

pip install calc-rtd

Gratuito, licença MIT. Windows para servidores RTD reais; a fonte simulada roda em qualquer sistema. Python 3.9+. 
from calc_rtd import RtdSession

with RtdSession() as rtd:
    rtd.subscribe("Vendor.ProgID", ["ACME", "LAST"])
    for update in rtd.updates():
        print(update.value)

Três formas de receber os dados

Escolha a que combina com o seu programa. Elas podem ser misturadas na mesma sessão.

  1. Iterar sobre as atualizações

    Um laço que recebe cada mudança assim que ela chega.

    for update in rtd.updates(timeout=30):
    if update.error:
        print("problem:", update.error)
    else:
        print(update.value)

  2. Ler o último valor

    Cada assinatura guarda o valor mais recente.

    acme = rtd.subscribe("calcrtd.sim", ["walk", "ACME", 38.5])
acme.wait(timeout=10)      # first value
print(acme.value)          # always the latest

  3. Callbacks

    Uma função chamada a cada atualização de um tópico.

    def on_price(update):
    if update.value > 40:
        print("ACME above 40:", update.value)

rtd.subscribe("calcrtd.sim", ["walk", "ACME", 38.5],
              callback=on_price)
rtd.run_for(60)

Teste sem nenhum servidor RTD

O ProgID calcrtd.sim é uma fonte simulada embutida na biblioteca: relógio, contadores, números aleatórios e passeios aleatórios. Todos os exemplos a usam por padrão, então rodam em qualquer máquina; depois é só trocar pelo ProgID e pelos tópicos do seu fornecedor.

rtd.subscribe("calcrtd.sim", ["clock"])

Verifique um servidor pela linha de comando

Cole uma fórmula que funciona no Excel. O comando imprime cada atualização e termina com código 0 se alguma chegou:

python -m calc_rtd "=RTD(Vendor.ProgID;;ACME;LAST)" --seconds 30

Vale saber

  • Windows e arquitetura. Servidores RTD são componentes COM. Quando o servidor é uma DLL, use um Python com a mesma arquitetura (32/64 bits) do Excel para o qual ele foi instalado.
  • Sem elevação. Rode o seu programa no mesmo nível de privilégio do aplicativo que alimenta o servidor RTD.
  • Threads. A sessão executa os servidores em uma thread própria, em segundo plano, então você pode usá-la de qualquer thread do seu programa.
  • Alguns servidores só aceitam o Excel. Fornecedores podem amarrar o servidor RTD ao próprio suplemento do Excel.
  • Os termos de uso do seu fornecedor de dados continuam valendo. Levar dados de um terminal para programas próprios costuma ser mais restrito do que exibi-los em uma planilha.
